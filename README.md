# ATM-CPP

A console-based ATM (Automated Teller Machine) simulation written in C++. This project is a personal learning log — it evolves alongside my progress in C++, so the codebase reflects new concepts as I pick them up (control flow, functions, data structures, OOP, file I/O, and beyond).

## About This Project

This isn't meant to be a polished, production-ready ATM system — it's a learning sandbox. Each stage of the project maps to what I'm currently learning in C++, so expect the code style and structure to grow more advanced over time (e.g. starting with plain functions and global variables, eventually moving to classes, file persistence, and better error handling).

## Features

Updating this list as I build things out.

 User login / PIN verification
 Check account balance
 Deposit funds
 Withdraw funds (with balance validation)
 Transaction history
 Multiple user accounts
 Data persistence (saving balances between runs)
 Input validation & error handling
